# TaskFlow Pro (com.appforge.taskflow) — Android APK Project

## Option 1: Compile APK in Android Studio (Local)
1. Open this folder in Android Studio.
2. Click **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
3. Your installable `app-debug.apk` will be generated in `app/build/outputs/apk/debug/`.

## Option 2: Compile APK in the Cloud (No Android Studio Required!)
1. Create a free GitHub repository and upload all files from this ZIP.
2. Go to the **Actions** tab in GitHub and run **Build Android APK**.
3. Download your compiled `.apk` file directly from the workflow Artifacts!
